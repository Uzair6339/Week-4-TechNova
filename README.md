# TechNova - Week 4 Performance & Accessibility

This is the optimized Week 4 version of the TechNova responsive webpage.

## Improvements
- Semantic HTML5 structure
- Skip-to-content link
- Keyboard-visible focus states
- Accessible section headings and navigation labels
- Descriptive ARIA label for the dashboard graphic
- Decorative chart elements hidden from screen readers
- Improved orange contrast for readable text
- Reduced-motion support
- Consolidated CSS selectors and variables
- No external fonts, JavaScript libraries, or unnecessary image requests
- Responsive layout retained from Week 2
- Lightweight CSS-only dashboard visualization

## Files
- index.html
- style.css

## Suggested testing
Test with Chrome Lighthouse and an accessibility checker such as WAVE or axe.
Check desktop, tablet, mobile, keyboard navigation, focus visibility, heading structure, contrast, and responsive layout.
